## Sobre mí

Estudio Ingeniería de Software en la UTA. Este semestre (julio a diciembre de 2026) llevo materias de cuarto y quinto nivel: Manejo y Configuración del Software, Metodologías Ágiles, Bases de Datos, Redes e Investigación Operativa.

Trabajo sobre todo en backend y en bases de datos relacionales. En los proyectos de grupo suelo encargarme de la integración y del manejo del repositorio con Git Flow: ramas `feature`, pull requests y revisión antes de fusionar.

En qué estoy ahora:

- EduMonitor AI: aplicación web de analítica académica sobre Moodle con un agente de IA. Soy Scrum Master y llevo el backend y la integración con Moodle.
- Gran Continental: venta de pasajes de buses interprovinciales. Mi parte es el módulo de compra del cliente (inicio, búsqueda, pasajeros, resumen y "Mis viajes").
- RutaFlow: formulario de solicitudes de cambio (RFC) con roles de pasajero, desarrollador y comité de cambios.
